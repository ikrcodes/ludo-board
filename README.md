# 🎲 Ludo Board (HTML + CSS)

A simple **Ludo Board** designed using only **HTML and CSS**.  
This is a beginner-friendly project created to practice **CSS positioning, box model, and layout techniques**.  

---

## 🔥 Features
- 🎨 Pure **HTML & CSS** project (no JavaScript, no frameworks)
- 🖼️ Creative Ludo board design
- 📄 Clean and simple folder structure
- 💡 Great for **beginners** learning frontend fundamentals

---

## 📂 Project Structure
📁 ludo-board
├── index.html # Main HTML file
├── style.css # CSS for board design
└── assets/ # (Optional) images or extra files

🎯 Purpose

This project was built to:

Practice CSS positioning (absolute, relative, etc.)

Understand box model & layout design

Create a fun UI without using Flexbox or Grid

🛠️ Tech Stack

HTML5

CSS3
